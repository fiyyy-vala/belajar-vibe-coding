# Belajar Vibe Coding API

Backend REST API starter menggunakan **Bun**, **ElysiaJS**, **Drizzle ORM**, dan **MySQL**.

## Quick Start

1. **Install dependencies**:
   ```bash
   bun install
   ```

2. **Setup Environment**:
   Salin `.env.example` ke `.env` lalu sesuaikan kredensial MySQL Anda:
   ```bash
   cp .env.example .env
   ```

3. **Jalankan Database Push (Drizzle)**:
   ```bash
   bun run db:push
   ```

4. **Jalankan Development Server**:
   ```bash
   bun run dev
   ```
   Akses `http://localhost:3000` di browser.
